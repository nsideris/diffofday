# Diff of the Day

What changed in AI today, for engineers who build with it.

Read it at [diffofday.com](https://diffofday.com) or follow the [RSS feed](https://diffofday.com/feed.xml).

## How it works

- `editions/<date>.json` holds one edition. Each top story has a stable `id`.
- `build.py` writes `index.html`, `editions/<date>.html` and `feed.xml`.
- `guard.py` stops a commit or a push that contains private words or secrets.

Summaries are written in our own words and link to the original source.
