Diff of the Day

What changed in AI today, for engineers who build with it.

Top stories

1 Chinese and North Korean state hackers now run ARTEX, an open-source multi-agent pentest framework, against web apps and APIs

Microsoft Threat Intelligence names six groups, including Salt Typhoon and Onyx Sleet, using ARTEX: a Go backend that coordinates LLM agents driving nmap, sqlmap, hydra, nuclei and Metasploit. One campaign made more than 151,000 failed sign-ins at up to 2,900 a minute, and some intrusions reached privileged access in under 3 hours. The repo was pulled from GitHub in October but forks circulate.

Microsoft Threat Intelligence · The Register · Nov 25–26 · discussion

2 Google will require AI agents to reach Workspace through its MCP servers from 1 February, and the public Gmail server cannot send

Google made eight Workspace MCP servers generally available and added an AI Tools Addendum to its API terms. Agents that keep calling the REST APIs drop to Standard quotas: 5,000 MCP requests per project, product and day, where one Gmail search counts as ten. Send, reply, forward and Drive sharing need partner access, and derived data such as embeddings may be capped at 30 days.

TechStackups · Hacker News · Nov 24–26 · 308 points · discussion

3 Inconsistent docs make coding agents spend 38% more tokens, even when they get the task right

Microsoft ran about 140 agent runs against documentation with planted contradictions. Sonnet 5.5 noticed the conflict but still used stale endpoints in 10 of 15 runs, and inconsistent docs cost 38% more tokens on average. The authors suggest letting agents cross-check docs against the code before they implement.

Microsoft for Developers · Nov 25–26

4 "Zero data retention" DeepSeek routes on OpenRouter traced to ByteDance's Ark API

An independent researcher fingerprinted inference providers by image-fetch IPs, request-ID and tool-call-ID formats and pricing. The write-up concludes that Novita, StreamLake and Ant Digital forward some DeepSeek traffic to ByteDance, an estimated 120–160B tokens a day for Novita before it lost its ZDR label on 20 Nov. The probe code is public.

kendell.dev · Hacker News · Nov 25 · 80 points · discussion

5 GitHub will bill Copilot code review to the organization by default from 30 December

For Copilot Business and Enterprise organizations that never saved a billing choice, reviews by licensed members will be charged to the repo-owning organization through AI Credits instead of each member's entitlement. Admins who want the current behaviour must pick "Member" in the Copilot policy settings before 30 December.

GitHub Changelog · Nov 25

6 Training agents to work as a team beat best-of-8 retries at an eighth of the tokens

Hugging Face's TRL walkthrough trains one shared Qwen3-0.6B policy for a four-agent task with async GRPO. Success rose from about 7% to 82%, held-out success reached 81%, and tokens per team fell 37%. One attempt by the trained team beat an untrained team with eight retries (82% against 38%) at about 8k tokens instead of 103k. It reproduces on 2×H200 in about 5 hours.

Hugging Face · Nov 26

7 NVIDIA open-sources Nemotron 3.5 Parse, a 0.6B document parser with training data and a 7.6× speculative decoder

The release ships about 19M synthetic chart, table and multilingual OCR examples and a fine-tuning recipe. SFT plus GRPO raised the ParseBench score from 66.2 to 71.4, and a form-extraction recipe went from 0% to 96.6% first-attempt success. With the DFlash2 speculator one H200 parses about 20 pages a second.

NVIDIA · Hugging Face · Nov 26

Trends

Platforms put agents on a meter — Google forces agents onto quota-limited MCP servers, GitHub moves Copilot review billing to the org, and heavy users keep hitting hourly and weekly caps on coding agents.
Agent input quality is a cost — Inconsistent docs cost 38% more tokens, vague prompt words get model-specific meanings, and review guides mined from past comments steer code-review agents.
Agentic attacks and opaque supply chains — State groups run an open-source multi-agent pentest tool, ZDR routes end at ByteDance, and canary prompts show providers keeping data.
Keep the human on taste and decisions — jxnl on owning what you ship, Uncle Bob supervising agents a minute or two an hour, and a growing view that product decisions, not code, are now the bottleneck.
